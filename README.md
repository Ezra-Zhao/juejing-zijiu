# 绝境自救

户外生存 + 野外急救短视频系列。每一集只教一个救命技能：开场先给一句「只剩十秒就做这一件事」，然后跟我做（编号步骤）、别这样做（致命错误）、口诀、练一练。

在危险里能照着一步一步做出来——这是这个系列的制作标准。

- 共 35 集（急救线 17 集 + 生存线 18 集），每集约 3–5 分钟
- 画面：电影级实拍风格动态镜头；配音：作者本人声音；字幕：全程底部字幕
- 背景音乐：作者本人赞美诗作品
- 视频文件在 [Releases](../../releases) 里（单集文件较大，走 Release 资产分发）
